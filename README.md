# SOC Home Lab

## Overview
This repository documents the development of a personal Security Operations Center (SOC) home lab, designed to build hands-on experience in security monitoring, threat detection, log analysis, network security, and incident response.

The project will be developed step by step, with installation guides, configurations, detection rules, screenshots, and documented security investigations.

## Project Objectives
- Build an isolated virtual lab environment
- Deploy and configure a SIEM platform
- Collect and analyze Windows and Linux security logs
- Monitor network traffic and investigate suspicious activity
- Develop and test security detection rules
- Simulate controlled security incidents
- Document findings and incident response procedures

## Planned Technology Stack
| Category | Tools |
| --- | --- |
| Virtualization | VMware or VirtualBox |
| SIEM | Wazuh |
| Endpoint Monitoring | Sysmon, Wazuh Agent |
| Network Analysis | Wireshark, Suricata |
| Operating Systems | Windows, Ubuntu Linux, Kali Linux |
| Security Framework | MITRE ATT&CK |
